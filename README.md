Portfólio Corretor Assis 🏡
Este projeto é um portfólio digital desenvolvido para o corretor Assis, com o objetivo de apresentar imóveis, informações de contato e destacar sua atuação no mercado imobiliário.

🚀 Tecnologias utilizadas
HTML5 para estruturação das páginas

CSS3 para estilização e responsividade

JavaScript para interatividade

Bootstrap para componentes visuais e layout responsivo

📂 Estrutura do projeto
index.html → Página inicial com apresentação do corretor

sobre.html → Informações sobre a carreira e experiência

imoveis.html → Catálogo de imóveis disponíveis

contato.html → Formulário e dados de contato

🎯 Funcionalidades
Apresentação profissional do corretor

Catálogo de imóveis com imagens e descrições

Formulário de contato integrado

Design responsivo para dispositivos móveis
